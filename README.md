# 🔞 Validador de Maioridade

Um projeto simples em **JavaScript** para validar se um usuário atingiu a maioridade legal (18 anos) com base no ano de nascimento informado.

## 🌟 Visão Geral

Este projeto é uma ferramenta fundamental para qualquer aplicação que exija a confirmação da idade do usuário para acesso ou cadastro. É um exercício prático que demonstra a utilização de estruturas de controle e manipulação do DOM em JavaScript puro.

### 💡 Funcionalidades

* **Validação de Idade:** Calcula a idade do usuário usando o ano de nascimento e o ano atual.
* **Aviso de Maioridade:** Exibe uma mensagem clara indicando se o usuário é maior ou menor de idade.
* **Feedback Visual:** Altera o *layout* e/ou texto para fornecer feedback imediato ao usuário.

## 🚀 Como Executar

Este projeto é totalmente baseado em *front-end* e não requer nenhuma configuração de *backend* ou instalação de dependências.

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/VictorMartelli/validador-maioridade.git](https://github.com/VictorMartelli/validador-maioridade.git)
    ```
2.  **Navegue até o diretório:**
    ```bash
    cd validador-maioridade
    ```
3.  **Abra o arquivo:**
    Simplesmente abra o arquivo `index.html` no seu navegador favorito.
